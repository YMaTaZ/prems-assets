# prems-assets

KKH PREMs Toolkits 的 **PDF 资产仓库**，托管于 GitHub Pages（与主站同域，供 iframe / PDF.js 直接加载）。

**在线地址：** https://ymataz.github.io/prems-assets/

## 内容

| 文件 | 说明 |
|---|---|
| `resource-guide.pdf` | PX Dashboard 资源指南（约 56 MB） |
| `checklist.pdf` | Dashboard Action Checklist |

## 更新方式

替换对应 PDF 文件后 push 到 `main`，GitHub Pages 自动重新部署（约 1-2 分钟）。主站 [kkh-prems-toolkit](https://github.com/YMaTaZ/kkh-prems-toolkit) 无需任何改动，预览与下载自动指向最新文件。

## 为什么单独建库

- 主站仓库保持轻量（不含 56 MB 大文件），每次部署更快
- 同域（`ymataz.github.io`）托管，浏览器可正常内嵌显示，不受跨域限制
